The Economics of Early Detection

Chronic disease burden & healthcare sustainability in Saudi Arabia.

This capstone combined Saudi Ministry of Health open data with published scientific literature to examine how chronic disease—particularly diabetes and its complications— can create long-term financial pressure, and where earlier detection and prevention could reduce downstream treatment costs.

PROJECT 03 · AUTOMATION 03
Automated Review Reporting & PowerPoint Generation

From structured Excel review data to presentation-ready reporting.

Built a Python workflow that reads structured review data from Excel, normalizes status values, consolidates reviewer comments, dynamically determines slide capacity based on text length, and generates formatted PowerPoint reports from a predefined template.

Dynamic Slide splitting based on content length
Auto Formatting copied from template

Repeatable Standardized reporting workflow
01 · Excel Input Output names, statuses, and reviewer columns.
02 · Clean & Normalize Status values and text standardized before processing.
03 · Consolidate Notes Meaningful reviewer comments combined per output.
04 · Layout Logic Text length determines record distribution across slides.
05 · PPT Output Formatted presentation files generated automatically.

def build_review_report(records, template):
    cleaned = normalize_status(records)
    notes = aggregate_reviewer_notes(cleaned)

    slides = split_records_into_slides(
        notes,
        capacity=estimate_text_units(notes)
    )

    for batch in slides:
        slide = copy_template_formatting(template)
        write_review_rows(slide, batch)

    return generate_presentation(slides)
